사용 안내

설치부터 필요한 설정까지, 순서대로 안내합니다.

SilentStream은 방송·녹화와 강의 자료 공유를 자동으로 처리합니다. 강의실 담당자는 전달받은 설치·호실 링크와 지정 Google 계정을 사용하세요.

설치·첫 실행 일상 사용·제어판 녹화·교시 VOD 폰 원격 제어 설정·관리 문제 해결·이용 안내

1. 설치·첫 실행

처음 한 번, 강의실 PC와 휴대폰을 연결하세요

  1. Windows 10/11 64비트 강의실 PC에서 호실 전용 링크·지정 Google 계정으로 로그인합니다. 개인 PC는 일반 설치 파일을 사용합니다.
  2. 호실 확인 → 다운로드·실행 → Windows 관리자 승인 → 캡처 동의. 파일은 Ctrl+J에서 찾고 재로그인은 같은 계정으로 합니다.
  3. 휴대폰도 같은 계정으로 호실 링크를 열어 온라인을 확인합니다. Wi-Fi·PIN은 불필요합니다. Chrome 메뉴·iPhone Safari 공유 메뉴에서 홈 화면에 추가합니다.
  4. YouTube는 안내받은 방송용 계정·채널을 별도로 연결하고 첫 방송의 실제 소리를 확인합니다.

온라인은 PC 연결 상태입니다. 첫 라이브는 채널 활성화 대기가 필요할 수 있습니다. 기관의 설치 차단·관리자 비밀번호 요청은 관리자에게 문의하세요.

2. 일상 사용·제어판

PC와 음향 장비를 켜면 자동으로 시작합니다

방송은 기본 일부 공개입니다. 인터넷이 끊겨도 백업 녹화는 계속되며 송출을 재시도합니다. PC 상태 점은 표시 설정을 켜면 보입니다.

초록: 방송 중노랑: 연결·준비 중빨강: 오류·재시도 중

기기 관리 → 방송 시작 / 방송 중지로 수동 조작합니다. 방송 중지 후에도 녹화는 계속됩니다. PC 제어창은 Ctrl+Shift+F12로 엽니다.

3. 녹화·교시 VOD

교시 영상과 재생목록을 자동으로 모읍니다

  • 교시 영상: 직접 연결 화면의 시간표에 따라 교시별 일부 공개 VOD를 업로드합니다. 요일별·당일 시간표를 지원합니다.
  • 재생목록: 호실·한국 날짜별 평일 목록에 교시 영상을 추가합니다. 오늘 재생목록 링크 복사 / 다른 날짜 찾기로 공유합니다. 생성·인증·동기화 후 복사할 수 있습니다.
  • 교시 업로드: 날짜별 상태·영상 링크를 확인합니다. 예상 시간은 추정이며 YouTube 처리는 별도입니다. 할당량 부족분은 대기 후 업로드합니다.
  • PC 녹화본: 내 비디오의 MediaCaptureHelper 폴더에 기본 7일·100GB까지 보관합니다. PC 설정에서 변경할 수 있습니다.
교시 음성만 받기

직접 연결의 음성 받기는 로컬 M4A가 없으면 접근 가능한 YouTube VOD에서 복구합니다. 비공개·삭제·로그인 필요 영상은 복구하지 못할 수 있습니다.

4. 폰 원격 제어·자료

필요한 자료와 기기 기능을 한곳에서

마이크 입력현재 조용함은 데이터 정상·낮은 음량입니다. 발성 후 소리를 확인하세요. 장치 인식·데이터 중단·캡처 오류는 별도 표시합니다. 입력 다시 연결은 설정 유지, 입력 복구는 앱 음소거·게이트 해제와 0 게인 복원입니다.
PC 전원
(관리자)		지금 PC 종료 / 종료 예약을 확인 후 실행합니다. 방송·녹화를 마감하며 다른 앱의 미저장 내용은 사라질 수 있습니다. 한국 시간 3분 이후~30일 이내 1회 예약, 2분 전부터 마감합니다. 전원 켜기는 지원하지 않습니다.

조작에는 최신 앱·도우미와 온라인 PC가 필요합니다. 오프라인에서는 동기화된 이력만 보입니다. 전체 입력 자동 모드는 새 웹캠·헤드셋 마이크도 포함합니다.

오프라인 종료 예약

호실·중앙 웹은 연결 후 등록 요청을 저장하며 종료 3분 전까지 미연결이면 만료합니다. PC가 확인한 예약은 휴대폰을 닫아도 남습니다. 직접 연결은 온라인이 필요하며, 취소해도 마감된 녹화·방송은 재개되지 않습니다.

개인 PC 직접 연결

PC의 폰 원격을 켜고 http://<PC IP>:8787에 6자리 PIN으로 접속합니다. 외부는 같은 Tailscale 네트워크를 사용하며, 호실 Google 로그인과 별도입니다.

5. 설정·관리

새 기능은 앱과 도우미를 함께 확인하세요

앱은 시작 시·6시간마다 확인하며, 사용 중 받은 업데이트는 다음 종료·재시작 때 적용합니다. 도우미는 수업 후 PC 제어창의 중지로 방송·녹화를 마감 → 도우미 업데이트 → 관리자 승인. 방송만 중지하면 갱신할 수 없습니다.

Windows 설정 → 앱에서 Media Capture Helper를 제거해도 녹화 파일·설정은 자동 삭제하지 않습니다.

설정·로그·알림

설정·로그는 %AppData%\MediaCaptureHelper에 있습니다. Telegram 알림은 PC 설정에서 봇 토큰·채팅 ID를 입력하고 시험합니다. 비밀번호·토큰·인증번호는 공유하지 마세요.

6. 문제 해결·이용 안내

막히면 연결·계정·실제 소리를 확인하세요

  • 권한 없음: 배정된 Google 계정과 호실을 확인합니다. PC 전원은 관리자 전용입니다.
  • 오프라인: PC 전원·인터넷·앱 연결을 확인하고 새로고침합니다.
  • 소리 없음: 발성·음량 확인 → 마이크·수신기 연결·장비/Windows 음소거 확인 → 필요 시 입력 복구.

본인 소유·관리 권한이 있는 PC에서 캡처 동의를 받고 사용하세요. 백업은 PC에, 라이브·교시 영상은 지정 YouTube 채널에 저장됩니다. 중앙 관리에는 상태·영상 링크가 전송됩니다. 인증 토큰은 보호해 저장합니다.
