# M111/M113 실기기 증거 최종 판정

- 판정일: 2026-08-23
- 원본 증거: `0715 점검/M111 점검/field-test-results/M111_20260715_131327`, `0715 점검/M113 점검/field-test-results/M113_20260715_072938`
- 적용 범위: 2026-07-15에 수집한 당시 앱의 동작 증거. 현재 v0.4.0 원격 점검 서비스의 실기기 합격 증거로 재사용할 수는 없다.
- 판정 원칙: 기계 산출물이 직접 입증한 항목만 PASS로 분류했다. 사람의 청취·폰 조작·외부망 접속이 필요한 항목은 자동 결과가 정상이어도 미확인으로 남겼다.

## 결론

두 기기 모두 기본 송출·녹화, 150분 무충돌, 네트워크 복귀, 제거 격리, 재부팅 후 자동 시작과 새 녹화 성장은 통과했다. 그러나 현재 상태는 **조건부 통과이며 현장 배포 승인 불가**다.

배포를 막는 항목은 다음과 같다.

1. 두 기기 모두 인위적 분할 승인 카드가 나타나지 않아 `approve/merge/skip`가 전부 `no-card`였다.
2. M111의 실제 5·6교시 분할이 `세션 파일 없음 또는 추출 불가`로 실패했다.
3. 두 기기 모두 오디오를 사람이 직접 청취한 증거가 없다. M111은 무음 경고와 회복이 반복됐고, M113은 두 입력의 무음 경고가 장시간 기록됐다.
4. Cloudflare 외부망 접속, 폰 PWA, Telegram, 다중 브라우저 제어권, 자동 품질 하향, 복구 백업은 미실시 또는 준비 안 됨이다.
5. 당시 진단 JSON에 전체 FFmpeg 명령줄과 송출 대상이 기록됐다. 기존 M111/M113 송출 키는 노출된 것으로 보고 교체해야 한다. 현재 코드는 RTMP URL 전체를 로그에서 마스킹하도록 수정했다.
