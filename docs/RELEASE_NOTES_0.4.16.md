# 0.4.16 — 기기별 강의자료 Drive와 담당자 전용 링크

- 중앙 관리에서 기기별 공용 계정 소유 폴더·자료 담당자를 지정한다. 기존 관리자/호실 제어 역할과 분리한다.
- PC 앱은 중앙에서 지정한 기기 폴더만 사용한다. 미지정/구버전 임의 폴더 설정은 자동 업로드하지 않는다.
- 공용 계정 연결 후 폴더 권한을 소유자와 지정 담당자(reader)로 제한하고 다시 조회해 확인한다. 상위 폴더의 외부 공유를 제거할 수 없으면 중단한다.
- 담당자 컨트롤러 USB 자료 탭에 Drive 바로가기를 추가한다. PC가 오프라인이어도 이미 확인된 링크는 사용할 수 있으며 Google이 실제 계정 권한을 검사한다. 권한 확인 대기·담당자 미정은 비활성화한다.
- 담당자 변경·해제는 실제 PC 권한 반영까지 대기 상태로 표시한다. 기존 유효 자료 담당자의 중앙 계정을 먼저 삭제하거나 담당 호실에서 제외할 수 없다.
- 로컬 7일 보관 규칙과 기존 서명 도우미/부팅 점검 0.4.12를 유지한다. 실제 계정·폴더ID·OAuth 토큰은 공개 소스에 포함하지 않는다.
