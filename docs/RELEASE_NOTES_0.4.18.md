# Media Capture Helper 0.4.18

- 정상적으로 입력 데이터가 들어오는 무음은 현재 조용함 안내로 표시합니다. 방송 중 치명 오류와 무음 자동 재연결을 제거했습니다.
- 장치 인식 안 됨, 입력 데이터 중단, 마이크 캡처 오류를 별도 상태로 표시합니다. 데이터 중단만으로 케이블 불량을 확정하지 않습니다.
- PC 앱과 직접 원격·호실 웹에 같은 상태 구분을 반영하고, 첫 입력 데이터를 받기 전에는 기존 장애를 복구로 처리하지 않습니다.
- 원격 상태에 앱 버전을 추가해 현장 적용 여부를 확인할 수 있습니다. 기존 연결 도우미 0.4.12와 검증된 서명 자료를 유지합니다.

검증: Core586·Windows 오디오10·JavaScript146, 총742개 통과. PC 앱 빌드 경고·오류0. 현장에서는 업데이트 적용 시 앱을 안전하게 재시작합니다.
