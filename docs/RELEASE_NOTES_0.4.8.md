# Media Capture Helper 0.4.8

- 한국 시간 기준 날짜·시각으로 PC 종료를 1회 예약하고 조회·취소할 수 있습니다. 기본값은 예약 없음이며, 설치·업데이트만으로 PC를 종료하지 않습니다.
- 종료 2분 전부터 녹화·방송을 마감하고 부팅·저장장치 안전 점검을 수행합니다. 점검·마감 실패 시 종료하지 않으며, 준비 지연 시 최소 60초의 취소 시간을 확보합니다.
- 예약은 PC에 저장되어 휴대폰을 닫아도 유지됩니다. 앱 종료·절전 등으로 예약 시각을 놓치면 뒤늦게 종료하지 않습니다.
- 최신 연결 도우미는 종료 예약과 마이크 원격 제어 명령을 전달합니다. 기존 마이크 자동 포함·느린 복구 간격을 유지합니다.
- 기존 서명 개인키 분실에 대응해 새 운영 키로 서명한 부팅 점검과 관리자 복구 설치 패키지를 제공합니다. 서명 검증을 유지하며, 기존 도우미의 신뢰키는 해당 PC에서 관리자 설치로 전환해야 합니다.

기존 앱은 온라인 상태에서 자동 업데이트를 다운로드하고 다음 종료·재시작 때 적용합니다. 호실·중앙 웹의 종료 예약에는 최신 PC 앱과 연결 도우미가 모두 필요합니다. 도우미 교체는 해당 호실의 공식 설치 페이지에서 복구 설치를 1회 진행하세요. 기기가 오프라인이면 현장 설치와 실제 동작 검증은 아직 수행할 수 없습니다.
