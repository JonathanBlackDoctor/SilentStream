# Media Capture Helper 0.4.7

- 연결된 모든 마이크 입력 자동 포함과 장치 재검색 기능을 유지합니다.
- 입력이 끊기면 한 번 빠르게 복구를 시도하고, 실패가 계속되면 30초 → 1분 → 2분 → 5분 간격으로 재시도합니다.
- 소리가 없는 입력은 처음 1분 동안 기다립니다. 이후에도 무음이면 5분, 10분 간격으로 재연결하여 불필요한 반복을 줄입니다.
- 실제 소리 입력이 돌아오면 복구 대기 상태를 초기화합니다. 개별 음소거와 정상 입력·시스템 소리는 유지합니다.

앱 자동 업데이트는 다운로드 후 다음 종료·재시작 때 적용됩니다. 오프라인 PC는 다시 연결돼야 다운로드할 수 있습니다. 기존 서명된 연결 도우미는 유지합니다. 호실 웹의 수동 마이크 명령에는 별도로 서명된 도우미 업데이트가 필요하지만, PC 앱의 자동 입력 감지·복구는 독립적으로 작동합니다.
