# 0.4.24 — 인증된 과거 로그·녹화 목록 조회

- 기존 인증된 앱 상태 연결에 최근 3일의 일별 로그 요약과 원본/교시 영상 파일 목록을 추가합니다. 연결 도우미를 다시 설치하지 않아도 해당 호실 관리자 상태에서 확인할 수 있습니다.
- 녹화와 분할 파일의 이름·크기·생성/수정 시각을 읽으며 원본을 수정하거나 삭제하지 않습니다. 앱 UI·방송 스레드 밖에서 수집하고 결과를 캐시합니다.
- 해당 앱·FFmpeg의 Windows 충돌과 디스크·전원·디스플레이 재설정 이벤트도 제한된 범위에서 함께 확인합니다.
- 로그 입력 크기·처리 시간·전송 크기를 제한하고 잘린 결과를 표시합니다. 스트림 URL·인증 토큰·계정·사용자 경로를 가립니다. 임의 경로나 명령 실행 기능은 추가하지 않습니다.
- 이번 릴리스는 앱 업데이트입니다. 검증된 서명 도우미0.4.22와 기존 공식 설치·복구 자산은 유지합니다.

현장 적용 전까지 과거 파일의 존재나 장애 원인 확인이 완료된 것은 아닙니다.
