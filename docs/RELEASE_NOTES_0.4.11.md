# Media Capture Helper 0.4.11

앱 제어창 하단에 **도우미 업데이트** 버튼을 추가했습니다. 공식 설치 파일과 통합 패키지를 자동으로 내려받아 크기·SHA-256을 검증하고, Windows 관리자 승인 후 기존 도우미를 갱신합니다. 웹에서 설치 파일을 받거나 Google 로그인을 다시 할 필요가 없습니다.

기존 호실 등록·연결 자격증명·설정·토큰을 보존합니다. 방송·녹음 중에는 적용하지 않으며 적용 직전에도 상태를 확인합니다. 다운로드를 취소할 수 있고 검증 실패 시 설치를 시작하지 않습니다. 앱은 갱신 후 일반 사용자 권한으로 다시 시작합니다.

앱 자체의 부팅 시 자동 업데이트는 유지됩니다. 도우미 신뢰키 교체에는 관리자 승인이 필요하며 이를 자동으로 우회하지 않습니다. 새 기기의 최초 중앙 등록은 기존 호실 설치 페이지를 이용합니다.
