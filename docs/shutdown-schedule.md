# 원하는 시각에 PC 종료하기

직접 연결 원격 화면의 **기기 제어 → 종료 날짜·시각**, 또는 호실 담당자 앱·중앙 관리의 **PC 종료 예약**에서 날짜와 시각을 선택하고 예약한다. 모든 입력과 예약 표시는 **한국 시간(Asia/Seoul)** 기준이다. 매일 반복이 아닌 **1회 예약**이며, 현재부터 **3분 이후~30일 이내**로 지정할 수 있다. 중앙·호실 웹에서는 기존 시스템 종료 권한과 동일하게 관리자만 예약·취소할 수 있다.

- 예약 성공은 PC가 저장을 확인한 뒤 표시한다. 새로고침하거나 휴대폰 화면을 닫아도 예약은 PC에 남는다.
- 기존 예약을 바꾸려면 **예약 취소** 후 새로 예약한다. 예약 번호가 달라진 오래된 화면의 취소 요청은 새 예약을 지우지 않는다.
- 지정 시각 **2분 전부터** 방송·녹화를 마감하고 기존 부팅·저장장치 안전 점검을 수행한다. 녹화가 이때 끝나므로 마지막 수업 이후로 충분한 여유를 두고 예약한다.
- 준비가 정상적으로 끝나면 지정 시각에 맞춰 Windows 종료를 요청한다. 안전 점검·마감이 지연되면 **최소 60초**의 취소 시간을 확보하므로 실제 종료가 늦어질 수 있다. 마감·안전 점검 실패 시 종료하지 않으며 실패 이유를 표시한다.
- **종료 예약 취소**는 Windows 종료 대기 중에도 사용할 수 있다. 마감 중에는 작업이 끝난 뒤 Windows 예약 취소를 확인하므로 응답까지 약 1분이 걸릴 수 있다. 이미 마감한 방송·녹화는 취소만으로 재개되지 않는다.
- **PC와 SilentStream 앱이 실행 중**이어야 한다. 예약 시 PC가 오프라인이면 새 예약이나 취소를 전달할 수 없다. 이미 PC가 저장한 예약은 이후 인터넷 연결이 끊겨도 로컬에서 시도한다. 다만 녹화 마감 등에 필요한 외부 응답 실패 시 종료를 차단할 수 있다.
- 앱이 다시 시작되어도 아직 남은 예약을 복원한다. 앱 종료·절전 등으로 예약 시각을 놓치면 `예약 시각 지남`으로 표시하고 뒤늦게 PC를 끄지 않는다. 절전 해제나 PC 전원 켜기 기능은 제공하지 않는다.
- 종료 준비 도중 앱이 중단되면 같은 명령을 자동 재시도하지 않는다. PC 상태를 확인한 뒤 다시 예약한다. Windows 종료 대기 뒤 앱이 계속 실행 중이면 결과 확인이 필요하다고 표시한다.

## 설치·운영 반영

직접 연결은 새 PC 앱이 필요하다. 중앙·호실 웹은 PC 앱·연결 도우미(Coordinator)·Worker·웹을 함께 업데이트해야 하며, 구버전 도우미에서는 버튼을 비활성화하고 업데이트 안내를 표시한다.

0.4.8 복구 설치본은 새 운영 공개키 `silentstream-ops-20261017`과 해당 키로 서명한 부팅 안전 점검을 포함한다. 기존 개인키를 잃어버린 기기는 **해당 PC에서** [M112 공식 설치 페이지](https://admin.silentstream.win/install/m112)를 열고 설치 파일을 받아 관리자 설치를 한 번 진행한다. 다른 호실은 주소의 `m112`를 `m111`, `m113`, `baek202`로 바꾼다. 기존 서명 검증을 유지하며 관리자 설치로 새 키와 최신 도우미를 등록한다. 중앙 계정 인증·패키지 SHA-256·서명 점검 및 설치 실패 시 복구 절차를 유지한다.

녹화가 끝난 뒤 복구 설치를 진행하고, 중앙 관리에서 온라인·연결 도우미 0.4.8 및 예약 버튼 활성화를 확인한다. **설치·업데이트만으로 종료를 예약하지 않는다.** 기기가 오프라인이거나 현장 접근이 불가능하면 배포된 설치 파일과 실제 기기의 설치 완료를 구분한다. 새 키의 개인키와 운영자 토큰 원문은 공개 패키지에 포함하지 않는다.

## 개발·검증

- `ShutdownScheduleManager`: PC AppData의 `shutdown-schedule.json`에 UTC 목표 시각과 일회성 실행 상태를 원자적으로 저장한다. 실행을 먼저 기록하여 앱 중단 뒤 같은 종료를 반복하지 않는다. 실패는 자동 재시도하지 않는다.
- `RemoteSystemShutdownService`: 기존 안전 점검·nonce 확인·녹화 마감·최종 점검·감사 기록·Windows 취소 절차를 재사용한다. 예약 실행에는 55초 제한을 적용한다.
- 인증된 `POST /api/system/shutdown/schedule`은 시간대가 포함된 `targetUtc`를 받는다. `POST /api/system/shutdown/schedule/cancel`은 현재 예약의 `id`를 받는다. `/api/status`와 WebSocket의 `shutdownSchedule`로 상태를 조회한다.
- 자동 검증은 가상 시계·임시 저장소·가짜 실행 콜백으로 수행한다. 테스트에서 실제 Windows 종료·예약 명령을 실행하지 않는다. 실기기 종료·현장 설치는 별도 검증 대상이다.
