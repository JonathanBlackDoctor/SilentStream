# Media Capture Helper 0.4.13

- 원격 PC 전원 카드에 지금 PC 종료 버튼을 추가했습니다. 확인 창에서 승인한 뒤 녹화·방송 저장과 부팅 안전 점검을 거쳐 종료합니다.
- 종료·재시작·방송 중지·전체 중지·재연결·점검 등 위험 동작은 확인 후 실행합니다. 직접 연결의 종료는 점검 후 확인 창을 한 번 표시합니다.
- Windows 60초 종료 대기 안내를 없앴습니다. 예약 시각까지 앱 내부에서 기다린 뒤 대기 안내 없이 종료하며, 예약 시각 전까지 원격 취소할 수 있습니다.
- 앱이 중단된 종료 대기는 자동 재실행하지 않으며, 절전 등으로 목표 시각을 놓치면 뒤늦게 종료하지 않습니다.
- 다른 프로그램의 미저장 내용은 사라질 수 있습니다. Windows 자체 종료 화면·업데이트·시스템/앱 기록은 유지합니다.
- 검증된 서명 도우미·부팅 점검 0.4.12를 재사용합니다. 새 신뢰키 등록 없이 앱·관리자 통합 설치본을 제공합니다.

방송·녹화 중 강제 적용하지 않습니다. 기존 앱은 자동 업데이트를 받은 뒤 다음 앱 시작 때 새 버전을 적용합니다. 웹의 즉시 종료 버튼은 새 앱이 연결돼 지원 상태를 알린 뒤 활성화됩니다.
