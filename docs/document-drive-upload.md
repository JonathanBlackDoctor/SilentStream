# 강의자료 Google Drive 자동 업로드

USB 문서 자동 보관을 마친 PPT/PPTX/PDF를 지정한 Google 계정 소유의 Drive 폴더에 업로드한다. 휴대폰으로 내려받았다가 다시 올릴 필요가 없다. 기본값은 꺼짐이며 각 강의실 PC에서 연결해야 한다.

휴대폰 컨트롤러의 USB 자료 탭은 PC 보관 목록·감지 상태·수동 다운로드용으로 유지한다. Drive 연결·업로드 실패 재시도는 PC 앱 설정에서 수행한다. 탭을 닫아도 동작하며, USB 자동 보관 자체를 끄면 Drive 업로드의 원본도 수집되지 않는다.

## PC에서 연결

1. 앱 제어창(Ctrl+Shift+F12)의 USB 자료 설정을 연다.
2. `보관된 자료를 Google Drive에 자동 업로드`를 선택한다.
3. 공용 업로드 계정 이메일과 그 계정에서 만든 폴더 링크를 입력한다. 개인 계정을 사용하지 않는다.
4. `Drive 계정 연결 및 설정 저장`을 눌러 브라우저에서 같은 공용 계정을 선택한다. Google Cloud 프로젝트에서 Drive API가 활성화되어 있어야 한다.
5. Google 동의 화면의 Drive 접근 범위를 확인하고 승인한다. 연결 확인 후 자동 업로드가 시작된다. 이미 보관된 자료도 대상이다.
6. 실제 USB 자료를 열어 보관을 확인하고, Drive에서 파일 내용과 업로드 완료 표시를 확인한다.

로그인 계정과 입력한 계정이 다르거나, 폴더 소유자가 다르거나, 휴지통/읽기 전용 폴더이면 차단한다. 연결 오류는 화면에 남기며, 업로드 실패 파일은 `실패한 Drive 업로드 재시도`로 명시적으로 재시도한다. 권한 연결만 다시 해도 기존 실패 기록은 자동으로 재시도하지 않는다.

## 권한과 데이터

- 이 구현은 Drive 웹에서 만든 기존 폴더를 대상으로 하므로 `https://www.googleapis.com/auth/drive` 권한을 명시적으로 요청한다. 이 권한은 **해당 폴더에만 제한되는 권한이 아니다**. 앱은 지정 폴더 검증 후 자료 업로드와 상태 조회만 수행한다. Google Picker 기반 `drive.file` 폴더 선택은 구현하지 않았다.
- YouTube 인증과 별도 DPAPI 암호화 파일 `document-drive-token.dat`를 사용한다. 백그라운드 작업은 로그인 창을 띄우지 않는다. 다른 PC로 암호화 파일을 복사하는 방식은 지원하지 않는다.
- 로컬 보관 파일은 유지한다. 공유 설정·공개 범위를 변경하지 않는다. PPT를 Google Slides로 변환하지 않는다.
- 업로드 이름은 `YYYY-MM-DD 원래파일명`이며 폴더 안에 바로 저장한다. 계정·폴더·SHA256·규칙 버전이 같으면 중복 업로드하지 않는다. 같은 이름의 다른 내용은 별도 Drive 파일로 저장한다.
- 파일 번호를 미리 발급하고 로컬 기록에 저장한 뒤 업로드한다. 응답 유실 후 수동 재시도 때 같은 번호를 조회하여 중복 생성을 막는다. 원본 SHA256 재검사와 Drive의 크기·MD5·부모 폴더·자료 해시 속성을 검증해야 완료 처리한다.
- 한 번에 하나, 초당 약 1 MB, 파일당 최대 256 MiB·10분, 한 번의 목록 처리에서 신규 시도 최대 10개다. 실패·중단 기록은 재시작 후에도 유지하며 자동 반복하지 않는다. 목록·대기 작업은 다음 처리로 남긴다.
- 상태 기록이 손상됐거나 저장할 수 없으면 업로드를 중단하고 기존 기록을 보존한다. 실제 대상 계정·폴더·토큰·개인 원본과 화면은 Git에 넣지 않는다.

## 구현과 검증 범위

`DocumentDriveUpload`는 앱 내부의 결정적 백그라운드 작업이며 AI·채팅·스케줄 자동화를 호출하지 않는다. 기존 `UsbDocumentArchive`의 보관 완료 자료만 사용한다. UI는 계정·폴더 연결/사용 중지/명시적 실패 재시도를 제공한다.

단위 및 모의 HTTP 검증: 중복·재시작·업로드 비활성화·실패 보존·동일 원격 ID 재시도·계정 불일치·다른 소유자·휴지통·쓰기 불가·손상 상태 보존·같은 크기/시각으로 변조된 로컬 파일·대상 변경·잘못된 폴더 링크·응답 유실 후 기존 파일 조회·서버 체크섬 불일치·resumable 전송 바이트/메타데이터·외부 업로드 주소 차단.

이 문서의 자동 검증은 실제 Google OAuth 승인·실제 Drive 업로드·운영 앱 배포·강의실 USB 감지를 대체하지 않는다. 별도 현장 검증이 필요하다.
