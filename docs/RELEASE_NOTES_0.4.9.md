# Media Capture Helper 0.4.9

- 호실 컨트롤러를 간결하게 정리했습니다. 방송 시작·중지 등 수동 제어와 교시별 업로드는 기본적으로 접혀 있습니다.
- 날짜별 재생목록의 실제 주소와 복사·열기를 제공합니다. 과거 조회를 오늘보다 5일 전으로 고정하던 동작을 제거했습니다.
- PC가 오프라인이어도 클라우드에 수신된 재생목록·교시별 업로드 기록·완료 영상 링크와 시간표를 조회할 수 있습니다. 빈 상태나 일부 목록 수신으로 기존 기록을 지우지 않습니다.
- 교시별 업로드 상태와 실제 전송 기록 기반 완료 예상 시각을 표시합니다. 오프라인·오래된 상태·재시도·실측 부족에서는 예상 시각을 표시하지 않습니다. YouTube 영상 처리 시간은 별도입니다.
- 한국 시간 기준 PC 종료 예약을 포함합니다. 오프라인에서도 클라우드에 요청을 저장·취소할 수 있으며, 지원되는 PC가 다시 연결되면 해당 PC에 한 번 등록합니다. PC 등록이 끝나기 전에는 종료가 보장되지 않으며, 종료 3분 전까지 연결되지 않으면 만료됩니다.
- 전달 실패·응답 미확인 요청은 자동 재전송하지 않습니다. 대상 PC가 바뀌거나 요청자의 관리자 권한이 사라지면 실행하지 않습니다. 설치·업데이트는 종료 예약을 자동 생성하지 않습니다.
- 녹화·방송 마감, 안전 점검 실패 시 종료하지 않는 동작 및 기존 마이크 자동 복구를 유지합니다.
- 음성 복구 정리가 끝나기 전에 완료로 표시되던 상태 경합을 수정했습니다.

앱 업데이트는 기기가 연결된 뒤 다운로드하고 다음 종료·재시작 때 적용됩니다. 종료 예약의 PC 등록과 마이크 원격 명령에는 최신 연결 도우미도 필요합니다. 이전 운영 키를 사용하는 기기는 호실 공식 설치 페이지에서 관리자 복구 설치를 한 번 진행해 신뢰키와 도우미를 갱신하세요. 오프라인 기기의 실제 설치·녹음·종료 검증은 별도로 필요합니다.
