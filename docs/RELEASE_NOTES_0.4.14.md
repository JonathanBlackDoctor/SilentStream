# Media Capture Helper 0.4.14

USB에서 연 PPT/PPTX/PDF의 PC 자동 보관이 끝나면, 지정한 공용 Google 계정의 Drive 폴더로 자동 업로드할 수 있습니다. 휴대폰으로 다운로드한 뒤 다시 업로드할 필요가 없습니다.

- PC 앱의 USB 자료 설정에서 업로드 계정과 해당 계정이 소유한 폴더를 연결하세요. 기본값은 꺼짐이며 Google Drive 권한 승인이 필요합니다. YouTube 로그인은 별도로 유지합니다.
- 다른 계정·다른 소유자·휴지통·쓰기 불가 폴더로의 업로드를 차단합니다. 전송 전 원본 내용, 전송 후 Drive 파일 크기·체크섬·폴더를 검증합니다.
- 같은 계정·폴더·파일 내용은 중복 업로드하지 않습니다. 실패·앱 종료로 중단된 업로드는 기록을 유지하며 PC 설정의 재시도 버튼으로 다시 시도할 수 있습니다.
- 컨트롤러의 USB 자료 탭은 PC 보관 목록·감지 상태 확인·수동 다운로드용으로 유지합니다. 탭을 열어두지 않아도 자동 보관·업로드는 계속됩니다.
- 파일당 최대 256 MiB, 순차 약 1 MB/s로 업로드하며 로컬 자료와 Drive 공유 설정은 유지합니다.

Drive 웹에서 만든 기존 폴더를 사용하기 위해 연결 시 전체 Drive 파일 접근 권한을 요청합니다. 지정 폴더에만 제한되는 Google 권한은 아닙니다. 실제 연결과 USB→Drive 업로드는 각 PC에서 확인해야 합니다.

앱·공식 설치 실행 파일은 0.4.14, 서명 검증된 연결 도우미와 부팅 안전 점검은 0.4.12를 유지합니다. 기존 신뢰키를 바꾸지 않습니다.
