# Media Capture Helper 0.4.12

- USB에서 여는 PPT·PPTX·PDF의 강의록 감지가 ETW 초기화 순서 때문에 시작되지 않는 문제를 수정했습니다.
- 감지 실패 시 예외 종류와 오류 코드를 표시하며, 실패 정리 중 감지 세션을 다시 열지 않습니다.
- 기존 신뢰키로 서명한 연결 도우미 0.4.12를 앱 업데이트에 포함합니다. 도우미는 서명·전체 파일 해시를 확인한 후 기존 등록과 설정을 보존해 갱신합니다.
- 정식 앱, 도우미, 관리자 통합 설치본을 함께 제공합니다. 기존 원격 웹 화면 수정도 포함합니다.

앱은 방송 중 강제로 재시작하지 않습니다. 새 앱을 적용한 뒤 USB 문서를 다시 열어 보관 완료와 원격 다운로드를 확인하세요. 도우미가 갱신되지 않은 설치는 앱 제어창의 도우미 업데이트 또는 공식 호실 설치 페이지를 사용하세요.
