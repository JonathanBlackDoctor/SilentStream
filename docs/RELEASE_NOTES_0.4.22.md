# 0.4.22

- YouTube가 하루 업로드 한도 초과를 HTTP 429로 반환해도 영상을 보존하고, 한도가 초기화된 뒤 자동 재개합니다.
- 채널 업로드 개수 제한은 별도로 24시간 대기한 뒤 재시도하며, 이 대기를 앱 재실행 후에도 유지합니다.
- 완료 큐의 오래된 항목이 정리돼도 영속 업로드 영수증으로 중복 업로드를 막습니다.
- 호실 원격 화면에서 선택한 날짜의 실패 영상만 다시 업로드할 수 있습니다. 앱과 연결 도우미가 모두 0.4.22 이상이어야 합니다.
- 이미 완료된 영상·다른 날짜·진행 중 작업은 재업로드하지 않습니다. 파일이 없거나 MP4에 영상 샘플이 없으면 재시도하지 않습니다.
- 녹화 구간이 비어 FFmpeg가 빈 출력을 반환한 경우 업로드 큐에 추가하지 않습니다.
- 녹화 종료 이후의 구간을 잘랐을 때 이전 프레임이 새 영상으로 남는 문제를 방지합니다.
- 기존 운영 서명키로 검증한 연결 도우미를 포함합니다. 새 인증 권한은 추가하지 않습니다.
