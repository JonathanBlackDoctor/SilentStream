# Media Capture Helper 0.4.6

- 연결된 마이크 입력을 자동으로 포함하고 USB 재연결·장치 ID 변경을 감지합니다.
- 입력 데이터 중단 및 장시간 무음에 대해 대기 간격을 늘리며 재연결합니다. 정상 입력과 시스템 소리, 개별 음소거 설정은 유지합니다.
- PC 직접 연결 원격 화면에서 마이크 선택·다시 연결·앱 음소거/게이트 해제를 지원합니다.
- 호실 웹에서 입력 상태를 표시합니다. 마이크 명령은 새 연결 도우미의 지원이 확인된 뒤 활성화됩니다.

## 적용 범위

앱 자동 업데이트는 다음 종료·재시작 때 적용됩니다. 오프라인 PC는 다시 연결돼야 다운로드합니다.

기존 운영 서명키가 현재 작업실 PC에 없어 이 릴리스는 연결 도우미를 자동 교체하지 않습니다. 함께 제공되는 inspection-agent-unsigned-0.4.6.zip은 운영 서명용 입력이며 현장 설치용 파일이 아닙니다. 기존 키로 서명·검증한 도우미 업데이트를 별도 전달해야 호실 웹의 마이크 명령이 활성화됩니다. PC 앱의 자동 입력 감지·복구와 직접 연결 원격 기능은 도우미 업데이트와 독립적으로 사용 가능합니다.

물리적 케이블·전원·Windows 권한 문제 해결이나 현장 음성 복구를 보증하지 않습니다. 실제 마이크 입력과 최종 녹화 소리를 확인하세요.
