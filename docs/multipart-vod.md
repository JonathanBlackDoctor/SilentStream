# 중단·재시작된 녹화의 교시별 업로드

한 교시가 여러 녹화 파일에 걸치면 각 파일과 교시가 겹치는 실제 구간을 별도 MP4로 잘라 올린다. 예: `1교시 (1/2)`, `1교시 (2/2)`. 긴 중단 구간을 이어 붙이거나 빈 화면으로 채우지 않는다. 라이브 송출과 원본 파일은 변경하지 않는다.

- 원래 교시·호실·날짜와 파일별 식별자를 각 업로드 작업/다운로드 자산에 보관한다. 각 업로드의 성공 경로에서 같은 날짜 재생목록에 편입한다.
- 한 파일이 없거나 컷에 실패해도 다른 파일은 처리한다. 다음 확인에서 복구된 파일을 추가할 수 있다.
- 앱 실행과 5분 간격 점검에서 최근 7일의 종료된 교시를 녹화 이력과 대조한다. 이미 큐에 있는 파일은 다시 자르거나 등록하지 않는다. 진행 중인 교시는 종료 경계에서 처리한다.
- 교시 종료 시 앱이 꺼져 있었어도 녹화 원본과 이력이 남아 있으면 다음 실행 때 복구한다. 녹화되지 않은 시간과 이미 지워진 원본은 복구할 수 없다.
- 파일 식별자가 없는 이전 버전의 업로드는 어떤 원본 구간이 포함됐는지 확정할 수 없어 자동 재업로드하지 않는다. 이 경우는 중복 생성 대신 수동 대조 대상으로 보존한다.

검사: 긴 중단 뒤 두 파일 각각 컷/등록, 활성 녹화 없는 재실행 복구, 중복 방지, 일부 파일 누락 후 복구, 기존 업로드 보존, 단일 파일 호환.
