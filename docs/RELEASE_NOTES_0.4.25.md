# Media Capture Helper 0.4.25

늦게 재부팅한 PC에서 새 날짜의 대기 항목 때문에 이전 수업일의 한도 관련 실패 복구가 누락되는 문제를 보완했습니다. 기존 1차 복구 표시가 저장된 큐도 확인하며, 저장된 채널 한도 발생일보다 앞선 최근 7일 내 마지막 실패 수업일 한 날짜만 검사합니다. 더 오래된 날짜로 계속 거슬러 올라가 재업로드하지 않습니다.

완료 영상의 VideoId·SourceKey, 영속 완료 기록, 빈 파일·누락 파일, 기존 대기 항목과 한도 대기 시각을 보존합니다. 이미 1차 복구 후 다른 날 다시 시도된 실패는 재등록하지 않으며, 그 여부를 확인할 시각이 없는 1차 복구 항목은 수동 검토를 위해 실패 상태로 남깁니다. 복구 표시를 2차로 저장해 재시작마다 실패 횟수를 초기화하지 않습니다. 오래된 큐에는 개별 오류 종류가 없으므로 한도 기록은 큐 전체의 근거이며 각 실패의 원인을 확정하지는 않습니다.

읽기 전용 진단은 오늘을 포함한 7일의 로그·녹화 파일 정보·Windows 이벤트를 수집합니다. 날짜가 바뀐 뒤 기기가 연결돼도 보존 기간 안의 사건 자료를 확인할 수 있습니다. 일별 입력·전체 수집 시간·파일 수·전송 크기 제한과 비식별화를 유지합니다.

기존 0.4.22의 검증된 서명 도우미를 그대로 포함합니다. 앱 복구와 진단 수집에는 도우미 교체가 선행되지 않아도 됩니다. 사용 중 받은 업데이트는 다음 종료·재시작에 적용되며, 배포 완료와 현장 적용·업로드 성공은 별도로 확인해야 합니다.
