# Media Capture Helper 0.4.15

USB 강의자료의 로컬 자동 보관본을 7일 후 자동 삭제합니다. Drive에 업로드된 자료와 USB 원본은 유지합니다.

- 앱 시작 시와 이후 15분마다 현재 보관 폴더에서 만료된 자료를 정리합니다. 보관 완료 후 7일(168시간)을 기준으로 하며, 기존 기록은 감지 시각을 기준으로 적용합니다. 앱이 꺼져 있었다면 다음 실행 시 정리합니다.
- Drive 업로드 성공 여부와 관계없이 로컬 보관기간을 적용합니다. 업로드가 꺼져 있거나 실패했더라도 7일이 지나면 로컬 보관본을 삭제합니다.
- 자동 보관 목록의 날짜·생성 파일명·크기·수정 시각이 일치하는 파일만 정리합니다. USB 원본, 보관 경로 밖의 파일, 사용자가 변경한 파일은 삭제하지 않습니다.
- 업로드·다운로드 중인 파일은 삭제를 미루며, 중앙 다운로드의 조각 사이에도 보호 시간을 둡니다. 같은 파일을 참조하는 중복 보관 기록은 가장 최근 보관 기록의 기간이 끝날 때 함께 정리합니다.
- 만료된 로컬 목록과 비어 있는 날짜 폴더도 정리합니다. Drive의 파일이나 업로드 중복 방지 기록은 유지합니다.
- PC 설정과 컨트롤러 USB 자료 탭에 7일 보관 규칙을 표시합니다. 컨트롤러 탭은 유지합니다.

앱·공식 설치 실행 파일은 0.4.15이며, 기존 서명 도우미·부팅 안전 점검0.4.12와 신뢰키는 유지합니다. 실제 현장 적용은 PC의 새 앱 수신·재시작 후 확인해야 합니다.
