# Media Capture Helper 0.4.10

USB의 PPT·PPTX·PDF를 열거나 PC로 복사할 때 같은 PC에 자동 보관합니다. 탐색기 미리보기도 포함될 수 있습니다. 신규 설치와 USB 설정이 없는 기존 설치에서 기본 켜짐이며 사용자가 저장한 꺼짐 설정은 유지합니다.

PC 설정에서 저장 위치·보관 상태를 확인할 수 있습니다. 온라인 PC의 USB 자료는 호실 원격 화면에서 날짜별 목록과 다운로드를 제공합니다. 문서 본문은 클라우드에 저장하지 않습니다.

앱과 관리자 도우미를 함께 업데이트해야 USB 읽기 감지가 동작합니다. 공식 설치 페이지의 복구 설치본은 앱과 도우미를 모두 포함합니다. 구버전 신뢰키를 사용하는 PC는 관리자 권한으로 복구 설치가 필요합니다.

복사는 한 번에 하나씩 초당 4MiB로 제한하며 SHA-256 중복 제거, 실패 표시, 사용자 재시도를 지원합니다. 실제 USB/문서 프로그램별 감지와 녹음 동시 성능은 현장에서 추가 확인해야 합니다.
