안녕하세요. [호실명] SilentStream 담당자로 등록되셨습니다.
PC를 켜면 방송·녹화가 시작되고, 교시 영상·재생목록과 USB 자료를 휴대폰에서 확인할 수 있습니다.

① 실제 방송에 사용할 Windows PC에서 아래 링크를 엽니다.
[설치 링크]
② [담당자 이메일]로 Google 로그인하고 호실이 [호실명]인지 확인합니다.
③ 「설치파일 다운로드」 → 받은 파일 실행 → Windows 권한 요청에서 「예」를 누릅니다. 파일은 브라우저 Ctrl+J에서 찾을 수 있습니다.
④ 설치 중 다시 로그인을 요청하면 같은 계정을 사용하고, 완료될 때까지 PC를 켜둡니다.
관리자 비밀번호 요청·설치 차단은 보안 설정을 바꾸지 말고 [관리자 연락처]에 문의하세요.

■ 휴대폰에서 연결
[원격 제어 링크]
위 링크를 [담당자 이메일]로 열고 [호실명]·「온라인」을 확인합니다. 같은 Wi-Fi나 PIN은 필요 없습니다.
Android는 Chrome 메뉴의 「앱 설치/홈 화면에 추가」, iPhone은 Safari 공유 → 「홈 화면에 추가」를 이용하세요.

■ 처음 사용할 때
마이크·수신기의 전원과 연결을 확인하고 관리자와 첫 방송의 실제 소리를 시험합니다. 「온라인」만으로 소리·방송이 정상이라는 뜻은 아닙니다.
담당자 로그인과 YouTube 방송 계정 연결은 별도입니다. 안내받은 방송용 계정을 사용하고 개인 계정을 임의로 연결하지 마세요.

■ 평소에는 이렇게 사용하세요
• 방송·녹화: PC와 음향 장비를 켜면 자동 시작합니다. 수동 조작은 「기기 관리」의 「방송 시작/방송 중지」를 사용합니다. 방송 중지 후에도 백업 녹화는 계속됩니다.
• 강의 영상: 교시 영상은 호실·날짜별 평일 재생목록에 자동 추가됩니다. 「오늘 재생목록 링크 복사」나 「다른 날짜 찾기」로 공유하고, 「교시 업로드」에서 진행 상태를 확인하세요. 예상 시간은 추정값입니다.
• USB 자료: USB의 PPT·PPTX·PDF를 열면 자동 보관하며 「USB 자료」에서 날짜를 골라 받습니다. USB를 꽂기만 해서는 수집하지 않습니다. 로컬 보관본은 업로드 성공 여부와 관계없이 7일 후 자동 삭제하며 USB 원본·Drive 파일은 유지합니다.
• 마이크: 「마이크 입력」에서 장치 선택·입력 다시 연결·입력 복구 후 실제 소리를 확인합니다.
• PC 종료 (관리자): 「PC 전원」에서 즉시 종료 또는 한국 시간 종료 예약을 선택합니다. 방송·녹화를 마감하며 다른 앱의 미저장 내용은 사라질 수 있습니다. 예약은 3분 이후~30일 이내 1회이며 2분 전부터 마감합니다.

조작·USB 다운로드에는 PC와 최신 앱·연결 도우미가 온라인이어야 합니다. PC가 꺼져도 동기화된 재생목록·업로드 이력은 조회할 수 있습니다. 오프라인 종료 예약은 연결 후 등록할 요청이며 종료 3분 전까지 연결되지 않으면 만료됩니다. PC 전원 켜기는 지원하지 않습니다.
Drive 자동 업로드는 관리자가 PC에서 공용 계정·폴더를 별도 연결한 경우에 사용합니다. 기기별 Drive 바로가기는 담당자 지정·공유 권한 확인 후 안내합니다.

■ 잘 안 될 때
• 권한 없음: 로그인 계정이 [담당자 이메일]인지 확인합니다.
• 오프라인: 강의실 PC 전원·인터넷을 확인하고 새로고침합니다.
• USB 감지 오류·새 기능 비활성: 방송 종료 후 PC 제어창(Ctrl+Shift+F12)의 「도우미 업데이트」와 Windows 관리자 승인을 확인합니다. 해결되지 않으면 문의하세요.
• 소리 없음: 마이크·수신기의 연결·음소거를 확인하고 입력 복구 후 시험합니다.
