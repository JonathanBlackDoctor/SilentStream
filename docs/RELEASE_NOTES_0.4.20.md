# Media Capture Helper 0.4.20

- 녹화가 중단·재시작된 교시는 각 녹화 파일의 실제 구간을 별도 영상으로 업로드합니다. 예: 1교시 (1/2), 1교시 (2/2).
- 앱 재실행 시 최근 7일의 완료 교시에서 아직 큐에 없는 파일을 찾아 복구합니다. 파일별 식별자로 중복 등록을 방지합니다.
- 각 영상은 원래 날짜·호실 재생목록에 개별 편입되며, 한 파일의 누락·실패가 다른 파일의 업로드를 막지 않습니다.
- 라이브 이력을 제어 서버에 전달합니다. 수업 종료 이후 라이브 편입은 PC와 독립된 서버 예약으로 처리하며, 서버 YouTube 연결이 필요합니다.
- 기존 마이크 복구, 고정 시간표, 녹화·송출 및 인증 설정을 유지합니다. 연결 도우미의 기존 0.4.19 서명 자료와 신뢰키를 재사용합니다.
