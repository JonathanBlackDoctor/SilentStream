# Media Capture Helper 0.4.3

텔레그램 알림 첫 줄에 알림을 보낸 PC 이름을 표시합니다. 호실명이 설정돼 있으면 `기기: M111 (DESKTOP-ABC123)` 형태로 함께 표시합니다. 일반 경고, 복구 알림, 테스트 알림에 모두 적용되며 호실명 변경은 다음 알림부터 반영됩니다.

검증: Core 테스트 465개 통과. Windows 자체 포함 배포 패키지 빌드.

기존 설치본은 자동 업데이트 확인 후 다음 종료·재시작에 적용됩니다. 오프라인 기기는 다시 연결돼야 업데이트를 받을 수 있습니다.

이 릴리스에는 특정 네 기기만 허용하는 실행 제한이 포함되지 않습니다. 해당 제한은 허용할 실제 기기 식별자 확인 후 별도 적용합니다.
