# Media Capture Helper 0.4.23

이전 버전이 YouTube 한도 응답을 일반 오류로 처리해 실패 상태에 남긴 최근 영상을 앱 시작 시 한 번 복구합니다. 저장된 채널 한도 기록이 있는 큐의 최근 7일 내 마지막 지난 수업일을 대상으로 하며, 기존 한도 대기 시각을 유지합니다.

이미 업로드된 영상은 큐와 영속 완료 기록으로 제외합니다. 빈 파일·없는 파일·다른 날짜·진행 중 작업은 복구 대상에 넣지 않습니다. 복구 여부를 저장해 재시작마다 실패 횟수를 초기화하지 않습니다. 방송·녹화 원본은 수정하지 않습니다.

이 복구에는 연결 도우미의 새 원격 명령이 필요하지 않습니다. 기존 0.4.22의 검증된 서명 도우미와 자동 업데이트 인증 경계를 유지합니다. 사용 중 받은 앱 업데이트는 다음 종료·재시작에 적용됩니다.
