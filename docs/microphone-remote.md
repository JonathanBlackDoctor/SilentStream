# 마이크 원격 선택과 입력 복구

호실 웹앱의 **마이크 입력**, 직접 연결 원격 화면의 오디오 영역에서 사용한다.

- **연결된 모든 입력 자동 사용**: 기본 모드. 연결된 캡처 입력을 모두 믹싱하고 녹화 중에도 약 2초마다 새 입력·재연결된 입력을 찾는다. USB 마이크, 라인 입력, 웹캠 마이크 등 Windows에서 활성화된 입력을 포함한다. 알려진 Stereo Mix/루프백 입력은 시스템 소리 중복 방지를 위해 제외한다.
- **선택 적용**: 위 전체 자동 모드 또는 실제 마이크 하나를 선택한다. 개별 마이크 선택은 전체 자동 추가를 끄고 기존 마이크 입력들을 이 장치로 대체한다. 시스템 소리는 유지한다.
- **입력 다시 연결**: 현재 마이크 캡처를 다시 연다. 음소거·게인·게이트 설정은 유지한다.
- **입력 복구**: 캡처를 다시 열고 앱의 마이크 음소거와 노이즈 게이트를 해제한다. 게인이 0이면 1배로 복원한다.
- 직접 연결의 **목록 새로고침**은 현재 장치를 다시 조회한다. 호실 웹앱은 약 10초마다 PC 상태를 갱신한다.

장치 누락·캡처 실패 또는 마이크 데이터가 5초 넘게 끊기면 해당 입력을 재연결한다. 실패 반복 시 재시도 간격은 30·60·120·300초로 늘어나며, 이후에도 최대 300초 간격으로 계속 시도한다. 캡처 오류가 나면 첫 재연결은 바로 시도할 수 있다.

입력 패킷이 정상적으로 들어오는 무음은 장치 장애로 취급하지 않는다. -60dBFS 이하가 10초 넘게 이어지면 PC와 원격 화면에 **연결됨 · 입력 데이터 정상 · 현재 조용함**을 표시한다. 이 상태는 정보 로그이며 기본 경고 알림·자동 재연결을 발생시키지 않는다. 소리가 다시 들어오면 안내를 해제한다. 앱 음소거·게인 0도 별도로 표시한다.

장치 상태는 다음처럼 구분한다. Windows의 장치 인식·캡처·패킷 수신을 관찰한 결과이며, 케이블의 물리적 불량 여부를 자동 확정하는 검사는 아니다.

| 표시 | 관찰 근거 | 처리 |
|---|---|---|
| 현재 조용함 | 장치·패킷 정상, 낮은 음량 | 안내만 표시, 캡처 유지 |
| 장치 인식 안 됨 | 지정 endpoint가 없거나 활성 입력으로 인식되지 않음 | 경고·재연결, USB·전원·Windows 장치 확인 |
| 입력 데이터 중단 | 마이크 패킷이 5초 넘게 수신되지 않음 | 경고·재연결, 연결·드라이버 원인 추가 확인 |
| 마이크 캡처 오류 | 인식한 장치의 캡처 열기·실행 실패 | 경고·재연결, 권한·장치·드라이버 확인 |

입력 장애는 `MicInputFailure`, 정상 패킷의 무음은 정보 수준 `MicSilent`로 기록한다. 방송 중에도 무음 자체를 치명 오류로 올리지 않는다. 무음 상태에서 나중에 패킷이 끊기거나, 소리가 없는 채로 데이터 수신만 복구돼도 주기 점검이 상태를 갱신한다. 실패 입력 재연결 중에는 해당 마이크에 짧은 공백이 생길 수 있다.

새 입력을 추가하거나 실패한 입력을 다시 열 때 정상 입력과 시스템 소리 캡처는 유지한다. 장치 목록 조회가 일시 실패해도 현재 입력들을 제거하지 않는다. 자동으로 제외된 이전 입력의 경고는 헬스 점검에서 해제한다.

PC의 입력·오디오 탭에도 **연결된 모든 입력 자동 추가** 체크박스가 있다. 개별 입력 제거 시 자동 추가를 끈다. 전체 모드에서는 새로 연결하는 웹캠·헤드셋 등의 마이크도 포함되며, 여러 마이크가 같은 소리를 받으면 울림·잡음이 늘 수 있으므로 불필요한 입력은 개별 음소거한다. 기존 개별 음소거·게인·게이트 설정은 자동 복구로 해제하지 않는다. 신규 입력에는 게이트를 자동으로 켜지 않는다. 같은 endpoint ID의 음소거는 실행 중 분리·재연결에도 유지되지만 다른 ID로 재인식된 장치는 새 입력으로 취급한다.

명령 성공은 신호 복구 보증이 아니다. 마이크 앞에서 소리를 내고 음량 막대가 움직이는지, 실제 송출에서 소리가 들리는지 확인한다. 캡처 중이 아니면 재연결/복구는 실행하지 않는다. Windows 녹음 권한, Windows 또는 장비 자체 음소거, 케이블 단선·연결 오류는 따로 확인해야 한다.

기존 원격 인증·호실 권한·설정 잠금이 적용된다. 호실 담당자는 본인 호실에서만 명령을 실행할 수 있다.

## 배포 의존성

이 기능은 PC 앱, Inspection Coordinator 연결 도우미, Cloudflare Worker 및 호실 웹 자산을 함께 업데이트해야 한다. 기존 0.4.3 보조 프로그램을 재사용하는 앱 전용 릴리스만으로는 호실 웹 명령을 전달할 수 없다. 업데이트 전 PC는 원격 마이크 기능 대신 업데이트 안내를 표시한다.

현장 검증: USB 마이크 선택 → 송출 시작 → 말하며 음량 확인 → 입력 다시 연결 → 앱 음소거/0 게인 후 입력 복구 → USB 분리·재연결 후 자동 재시도 확인 → 최종 수신 음성 확인.

전체 입력/반복 복구 현장 검증: 전체 자동 모드 → 두 입력 각각 발성 → 녹화 중 세 번째 입력 연결 → 입력 무음 지속 시 조용함 안내·재연결 없음 확인 → USB 분리·재연결/ID 변경 시 장애 표시·자동 복구·실제 녹화 확인. 디스크 삽입만 하는 경우와 파일 복사 부하를 주는 경우를 구분한다. 중요 녹화가 아닌 시험 녹화에서 수행한다. 가상 장치 테스트 통과는 M112의 전원·허브·드라이버 장애 해결을 보증하지 않는다.
