# SilentStream 사용자 안내

Windows 10/11 64비트 PC의 화면·소리를 YouTube에 일부 공개로 송출하고 PC에 백업 녹화합니다. PC를 켜면 자동으로 시작하며, 강의 영상·재생목록·USB 자료와 원격 제어를 제공합니다.

## 설치와 첫 확인

1. 강의실 담당자는 전달받은 호실 전용 설치 링크를 **실제 강의실 PC**에서 엽니다. 지정 Google 계정으로 로그인 → 호실 확인 → 설치파일 다운로드·실행 → Windows 관리자 승인을 진행합니다.
2. 휴대폰에서 담당 호실 링크를 같은 계정으로 열고 호실·온라인 표시를 확인합니다. 같은 Wi-Fi나 PIN은 필요 없습니다. Android Chrome 메뉴 또는 iPhone Safari 공유 메뉴에서 홈 화면에 추가할 수 있습니다.
3. YouTube는 **안내받은 방송용 계정**을 별도로 연결합니다. 마이크·수신기의 전원과 연결을 확인하고 첫 방송의 실제 소리를 시험합니다. 온라인 표시는 PC 연결 상태이며 방송·음향 정상의 보증은 아닙니다.

개인 PC는 [공식 다운로드](https://silentstream.win/)를 이용합니다. 설치 차단·관리자 비밀번호 요청은 담당 관리자에게 문의하세요. 계정·장치를 임의로 선택하지 않습니다.

## 평소 사용

| 할 일 | 사용 방법 |
|---|---|
| 방송·백업 녹화 | PC와 음향 장비를 켜면 자동 시작합니다. 수동 방송 시작·중지는 호실 화면의 **기기 관리**에서 사용합니다. 방송 중지만 하면 로컬 녹화는 계속됩니다. |
| 교시 영상·재생목록 | 직접 연결 시간표에 따라 교시 VOD를 업로드하고 호실·한국 날짜별 평일 재생목록에 자동 추가합니다. **오늘 재생목록 링크 복사 / 다른 날짜 찾기**로 공유합니다. 생성·인증·동기화가 끝나야 복사할 수 있습니다. |
| 업로드 확인 | **교시 업로드**에서 날짜별 진행 상태와 영상 링크를 봅니다. 예상 시간은 최근 기록의 추정이며 YouTube 처리 시간은 별도입니다. 할당량 부족 시 대기열에 남아 한도 초기화 후 업로드됩니다. |
| USB 자료 | USB에서 읽힌 **PPT·PPTX·PDF**를 자동 보관합니다. USB를 꽂거나 폴더만 보는 것으로는 수집하지 않습니다. **USB 자료 → 날짜 → 다운로드**를 사용합니다. 로컬 보관본은 업로드 성공 여부와 무관하게 **7일 후 자동 삭제**하고 USB 원본·Drive 파일은 유지합니다. |
| 마이크 | **마이크 입력**에서 장치 선택·입력 다시 연결·입력 복구를 사용합니다. 복구 후 실제 소리를 내어 음량을 확인합니다. 장비·Windows 음소거는 현장에서 확인합니다. |
| PC 전원 (관리자) | **지금 PC 종료 / 종료 예약**을 확인 후 실행합니다. 방송·녹화를 마감하고 종료하며 다른 앱의 미저장 내용은 사라질 수 있습니다. 한국 시간 3분 이후~30일 이내 1회 예약, 2분 전부터 마감합니다. [종료 안내](shutdown-schedule.md) |

조작·USB 목록·다운로드는 최신 앱·연결 도우미와 PC의 온라인 연결이 필요합니다. PC가 꺼져도 클라우드에 동기화된 재생목록·업로드 이력은 보이지만 현재 상태는 아닙니다. 오프라인 종료 예약은 **연결 후 등록할 요청**이며 종료 3분 전까지 연결되지 않으면 만료됩니다. PC가 등록을 확인한 예약은 휴대폰을 닫아도 남습니다. 전원 켜기는 지원하지 않습니다.

## PC 설정과 자료 보관

- **Ctrl+Shift+F12**로 PC 제어창을 엽니다. 호실명·음향·녹화 폴더·USB 자료 설정을 확인할 수 있습니다. 녹화는 기본 7일·100GB 한도이며 설정할 수 있습니다. USB 보관본의 7일 보관은 별도입니다.
- USB 자동 보관은 기본 켜짐이며, 저장해 둔 꺼짐은 유지합니다. 탐색기 미리보기도 읽기로 감지될 수 있습니다. 감지 실패는 USB·도우미·저장 공간을 확인하고 다시 열거나 재시도합니다. [USB 상세](usb-documents.md)
- Drive 자동 업로드는 기본 꺼짐입니다. 관리자가 **설정 → USB 자료**에서 공용 계정·소유 폴더를 별도로 연결합니다. YouTube와 별도 인증이며 Google 동의 화면의 Drive 접근 범위를 확인합니다. 실패한 업로드는 같은 PC 화면에서 명시적으로 재시도합니다. 기기별 Drive 바로가기는 담당자 지정·공유 권한 확인 후 안내합니다. [Drive 연결](document-drive-upload.md)
- 앱 업데이트는 다운로드 후 다음 재시작 때 적용됩니다. 도우미 갱신이 필요하면 방송 종료 후 **도우미 업데이트**와 Windows 관리자 승인을 진행합니다. [업데이트 안내](in-app-helper-update-0.4.11.md)
- Windows 설정 → 앱에서 제거합니다. 녹화 파일·설정은 자동 삭제하지 않습니다. 로그·설정은 PC의 %AppData%\MediaCaptureHelper에 있습니다. 비밀번호·토큰은 공유하지 않습니다.

## 개인 PC 직접 연결

PC 설정에서 폰 원격을 켜고 http://<PC IP>:8787로 접속해 제어창의 6자리 PIN을 입력합니다. 외부에서는 같은 Tailscale 네트워크를 이용합니다. 강의실 Google 로그인과는 별도 방식입니다. 직접 연결의 교시 자료는 **음성 받기**를 제공하며 로컬 M4A가 없으면 접근 가능한 YouTube VOD에서 복구합니다. 비공개·삭제·로그인 필요 영상은 복구하지 못할 수 있습니다.

## 문제 해결

| 증상 | 확인 |
|---|---|
| 권한 없음·담당 호실 없음 | 배정된 Google 계정과 호실을 확인합니다. |
| 오프라인 | 강의실 PC 전원·인터넷·앱 연결 후 새로고침합니다. |
| 소리 없음 | 마이크·수신기 연결·음소거 확인 → 입력 복구 → 실제 소리 시험. |
| USB 감지 실패·새 버튼 비활성 | 앱·도우미 업데이트와 USB 자동 보관을 확인합니다. 전원 버튼은 관리자 전용입니다. |
| 재생목록 없음 | 해당 날짜의 영상 업로드·YouTube 연결·앱 동기화를 확인합니다. 다른 날짜로 대신 복사하지 않습니다. |

해결되지 않으면 관리자에게 호실·오류 화면·문제가 발생한 단계를 전달합니다. 본인 소유 또는 관리 권한이 있는 PC에서 필요한 캡처 동의를 받고 사용하세요.

## 담당자 배정·메일 운영

- 표준 메일: [manager-install-email.txt](manager-install-email.txt). 지정 Google 이메일·호실·연락처를 확인하고 배정 → 권한 저장 검증 → 모든 대괄호 필드 치환 → 발송 → 최초 연결·음향 확인 순서입니다. 수신자·호실을 추측하지 않습니다.
- 담당자는 manager와 맡을 호실만 지정합니다. 기존 관리자 역할은 유지합니다. PC 전원은 admin 전용이며, 담당자 배정이 Drive 열람 권한을 자동 부여하지 않습니다.
- 설치: https://admin.silentstream.win/install/{roomId}, 휴대폰: https://{roomId}.silentstream.win/. roomId는 m111/m112/m113/baek202이며 메일에는 해당 호실 링크만 넣습니다.
- 사용자 승인에 따른 담당자 지정 후 Gmail 발송 절차는 유지합니다. 이번 안내 갱신은 발송 작업이 아닙니다. 발송 결과 확인·중복 방지, 계정·연락처·토큰 Git 제외 원칙을 유지합니다. 담당자 저장 시 자동 발송되는 기능은 없습니다.
