# Media Capture Helper 0.4.4

모바일 원격 제어에 **오늘 재생목록 링크 복사**를 추가했습니다. 해당 강의실과 한국 날짜(Asia/Seoul)에 맞는 YouTube 재생목록만 복사합니다. 오늘 목록이 아직 없거나 생성·인증에 문제가 있으면 상태를 안내하며, 다른 날짜의 링크로 대체하지 않습니다.

- PC 직접 연결 화면에 오늘 재생목록 카드와 복사 버튼을 표시합니다.
- 호실 웹앱은 별도 웹 배포로 공유 링크 상단에 오늘 전용 복사 버튼을 제공합니다.
- 클립보드가 차단된 브라우저에서는 링크를 선택해 직접 복사할 수 있습니다.
- 복사 작업은 저장된 링크를 읽으며 YouTube API 호출이나 재생목록 생성을 하지 않습니다.

검증: Core 테스트 472개, 모바일 웹 동작/제어부 테스트 28개, Windows 앱 빌드.

기존 PC 설치본은 자동 업데이트를 확인한 뒤 다음 종료·재시작 때 적용합니다. 오프라인 PC는 다시 연결돼야 업데이트를 받을 수 있습니다. 이 앱 업데이트는 기존 서명된 점검 서비스와 0.4.3의 송출 보조 프로그램을 유지합니다.
