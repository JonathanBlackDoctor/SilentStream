# 0.4.17 — 공용 Google Drive 중앙 1회 연결

- 중앙 관리에서 공용 Google 계정을 한 번 연결하면 모든 등록 기기에 같은 연결을 사용한다. 공용 OAuth 토큰은 서버에서 암호화 보관하며 PC나 담당자 브라우저에 전달하지 않는다.
- 앱은 중앙 모드에서 개별 PC Google 연결·업로드·권한 변경을 중단한다. 서버가 온라인 기기의 USB 보관 자료를 기기별 폴더에 올린다. 중앙 모드 앱 0.4.17 이상에서 활성화한다.
- 중앙에서 담당자별 읽기 권한을 적용·검증하므로 PC 오프라인에서도 Google 권한 확인과 Drive 바로가기를 준비할 수 있다. 자료 전송 자체는 PC 연결이 필요하다.
- 업로드는 256KiB 조각, 실행당 최대8조각, 파일256MiB/10분, 영속 전송 위치/사전발급 ID, Drive SHA256·크기·폴더 확인을 사용한다. 실패는 명시적으로 재시도한다.
- 로컬7일 삭제, 기존 관리자 역할·기기별 폴더, 기존 서명 도우미/부팅 점검0.4.12를 유지한다.
