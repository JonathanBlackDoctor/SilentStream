# USB 문서 자동 보관과 원격 다운로드

USB의 PPT·PPTX·PDF를 프로그램이 읽으면 해당 문서를 같은 PC에 보관한다. 탐색기 미리보기도 읽기에 해당하며, USB를 꽂거나 폴더 이름을 조회하는 것만으로는 복사하지 않는다.

## 사용 방법
1. PC 제어창의 설정 → USB 자료에서 저장 폴더를 확인하고 ‘USB 문서 자동 보관 사용’을 켠 뒤 ‘USB 보관 설정 저장’을 누른다. 0.4.10부터 신규 설치와 USB 설정이 없는 기존 설치는 기본 켜짐이다. 사용자가 저장한 꺼짐 설정은 유지한다.
2. USB에서 문서를 열거나 PC로 복사한다. 파일은 Windows 문서 폴더의 SilentStream/USB 자료/한국 날짜에 저장된다. 같은 내용은 중복 보관하지 않는다.
3. 직접 연결 화면 또는 호실 원격 화면의 USB 자료를 펼치고 날짜를 선택한다. PC가 온라인이고 최신 앱·연결 도우미가 연결돼 있어야 목록 및 다운로드를 사용할 수 있다.
4. 실패한 파일은 USB·권한·저장 공간을 확인한 뒤 재시도한다. 원격 설정 잠금이 켜져 있으면 PC에서 설정한다. 보관 문서는 자동 삭제하지 않는다.

## 구성과 호환성
- 사용자 앱: 단일 복사 작업자, 128개 대기열, 256KiB 버퍼, 기본 초당 4MiB. SHA-256 계산과 임시 파일 완료 후 이동. 내용 중복은 기존 파일을 공유하며 다른 내용은 고유 이름으로 보존.
- 최소 1GiB 여유 공간을 남긴다. 원본 쓰기 공유는 허용하지 않아 수정 중인 파일은 실패할 수 있다. 복사 중 비활성화하면 해당 작업은 실패 상태로 중단한다.
- 앱 데이터 폴더의 usb-documents.json에는 로컬 경로·내용 해시·결과를 원자 저장한다. 앱 재시작 시 진행 중 작업은 실패로 복원하고 해당 작업의 임시 파일만 정리한다. 읽기 불가능한 카탈로그는 보존하고 수집을 중단한다.
- Broker: Microsoft.Diagnostics.Tracing.TraceEvent 3.1.21 기반 ETW. Storage bus type USB로 외장 SSD/UASP도 판별. 8초 임대가 만료되면 감지를 중단한다. 파일 내용은 읽지 않으며 대화형 사용자 세션의 대상 문서만 처리한다. 자체 앱·서비스 및 식별 가능한 검색/백신 프로세스는 제외한다.
- Coordinator: 기존 ACL/HMAC named pipe와 loopback bridge 인증으로 메타데이터를 전달한다. 활성 시 250ms 간격, 비활성 시 3초 간격. 연결 실패는 최대 30초 간격으로 완화한다. ETW 시작 실패는 자동 반복하지 않으며 기능을 껐다 켜 재시도한다.
- 원격: 기존 페어링/호실 담당자/관리자 인증 유지. 설정 잠금 유지. 카탈로그 ID로만 다운로드하며 절대 경로 입력을 받지 않는다.
- 중앙 다운로드: 요청별 256KiB 조각, 다음 요청이 이전 조각의 수신 확인 역할을 한다. 호실당 전송 하나, 권한·기기 연결을 각 조각마다 재확인. 문서 내용과 목록은 중앙 명령 이력에 저장하지 않는다. 오프라인 저장/다운로드 없음.
- 직접 다운로드: 인증 API에서 1분 유효·1회 사용 파일 전용 티켓을 발급하고 스트리밍한다. 재사용 가능한 기기 토큰은 다운로드 URL에 넣지 않는다. API 및 다운로드는 PWA 캐시 제외.
- 구버전 호환: 설정 필드는 추가형 기본값을 사용한다. 앱 usbDocumentsSupported와 도우미 remoteUsbDocuments가 모두 있어야 중앙 UI에서 지원됨으로 표시한다.

## API
- GET /api/usb-documents?date=YYYY-MM-DD&skip=0 : 100개씩 목록과 감지 상태.
- POST /api/usb-documents/settings : enabled. 폴더 설정은 PC 제어창에서만 변경.
- POST /api/usb-documents/retry : id.
- GET /api/usb-documents/{id}/download : 기존 인증을 사용하는 파일 스트림.
- POST /api/usb-documents/{id}/ticket : 브라우저 다운로드용 한시적 URL.
- POST /api/usb-documents/detector : loopback bridge 전용, 최대 64개 메타데이터.
- /api/usb-documents/enabled, /list, /chunk : 연결 도우미용 인증 경로.
- 중앙 /api/control/rooms/{room}/usb-documents 및 /{id}/download : 호실 인증·원격 중계.

## 패키징과 현장 확인
앱, Broker, Coordinator를 함께 업데이트해야 한다. Broker publish 폴더의 TraceEvent 및 native DLL을 포함해 기존 도우미 패키징 절차를 적용한다. 기존 서명·설치 권한 절차는 유지한다. 이번 작업은 로컬 publish 검증까지만 수행하며 배포·서비스 설치·운영 설정 변경은 하지 않는다.

현장 관리자로 도우미 설치 후 기능을 켜고 PowerPoint, Edge/Chrome PDF, Adobe Reader, 탐색기 복사/이동/미리보기를 확인한다. USB 연결·폴더 조회만으로 수집하지 않는지, 분리/재연결, 문서 변경, 동명 파일, 다운로드 해시, 녹음 동시 수행을 확인한다.

ETW는 클릭 의도가 아닌 파일 읽기를 관찰한다. 모든 앱에서 무손실 감지를 보장하지 않으며, 이동 중 원본이 먼저 삭제되거나 USB가 먼저 빠지면 실패할 수 있다. 관리자 권한이 없는 환경에서는 ETW 실측·2초 이내 시작·실제 녹음 동시 성능을 검증했다고 주장하지 않는다.
