# 앱 안에서 도우미 갱신 — 0.4.11
2026-10-17 · 확인대기. 운영 게시 완료, M112 실제 설치 대기.

## 사용
인터넷에 연결된 PC에서 SilentStream 앱을 시작하면 기존 자동 업데이트로 0.4.11을 받는다. 제어창(기본 단축키 Ctrl+Shift+F12) 하단의 **도우미 업데이트**를 누르고 Windows 관리자 요청을 승인한다. 웹에서 직접 파일을 받거나 Google 로그인을 다시 할 필요가 없다. 앱을 사용하는 Windows 계정에서 승인해야 하며, 다른 계정으로 실행해 기존 앱 경로·DPAPI 인증이 맞지 않으면 변경 전에 중단한다.

앱과 같은 정식 릴리스의 설치 EXE와 통합 ZIP만 사용한다. GitHub 공식 주소·릴리스 태그·크기·SHA-256을 확인하고 다운로드 취소를 지원한다. 도우미 교체 시 앱이 잠시 재시작된다. 방송·녹음 중에는 버튼과 적용 직전 검사로 중단하며, 적용 실패 시 기존 설치 복구 절차를 사용한다.

기존 호실/기기 ID, 암호화된 연결 자격증명, 토큰, 사용자 정책은 보존한다. 관리자 승인은 생략하지 않는다. 도우미 완전 자동 갱신을 구현했다고 주장하지 않는다. 최초 기기 등록은 기존 호실 설치 페이지를 이용한다.

USB 보관에는 파일마다 팝업·소리·자동으로 열리는 창을 추가하지 않았다. 설정·처리 상태·실패 목록은 사용자가 앱 제어창이나 원격 화면을 열었을 때 확인할 수 있다.
